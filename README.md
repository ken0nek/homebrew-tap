# Ken0nek Tap

## How do I install these formulae?

`brew install ken0nek/tap/<formula>`

Or `brew tap ken0nek/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "ken0nek/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
